“Good programmers write code that humans can understand.” - Martin Fowler Have you ever read a line of code and thought, “this is great, but I’m not sure I understand what’s making it work”. It may have even been your own code you were reading when having this epiphany. In either case, Martin Fowler’s statement is a powerful one, and few have tried to refute it.
